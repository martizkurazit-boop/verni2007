//Доступ

Вход.

Админка работает напрямую с репозиторием GitHub: статьи и картинки сохраняются в него, а сайт пересобирается автоматически. Нужен персональный токен с правом записи.

  1. Откройте github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Repository access — только репозиторий —.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Скопируйте токен и вставьте сюда.

Токен хранится только в этом браузере и уходит исключительно на api.github.com. На чужом устройстве снимайте галочку — тогда он забудется при закрытии вкладки.

Содержание

Вставьте статью как есть — из документа или заметок. Абзацы разберутся по одному, дальше каждому назначается роль.

Внутри текста работает разметка: **жирный** и [ссылка](https://…). Заголовки H2 попадают в оглавление статьи.
